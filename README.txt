ADELE SUSHI - сайт доставки
===========================

Структура:
  index.html        - страница
  style.css         - стили
  js/config.js      - НАСТРОЙКИ: номер WhatsApp, телефон, соцсети, часы, видеоотзывы
  js/menu.js        - МЕНЮ: позиции, цены, описания (рус/каз), фото
  js/app.js         - логика (корзина, заказ в WhatsApp, язык)
  img/              - логотип, иконки; img/menu/ - фото блюд

Заливка на hoster.kz:
  1. Войти в панель hoster.kz -> хостинг -> cPanel (или "Файловый менеджер").
  2. Открыть папку public_html (или папку домена adelesushi.kz).
  3. Загрузить ZIP и нажать "Extract/Распаковать" - так, чтобы index.html лежал прямо в public_html,
     а не в подпапке.
  4. В cPanel включить бесплатный SSL (Let's Encrypt / AutoSSL), чтобы сайт открывался по https.
  5. Домен .kz начинает открываться через 1-24 часа после регистрации (DNS).

Перед сдачей клиенту:
  - В js/config.js заменить whatsapp: "77058254190" на номер заведения "77054936040".
  - Подставить фото блюд (см. img/menu/README.txt).
  - Казахские тексты дать проверить носителю языка.
